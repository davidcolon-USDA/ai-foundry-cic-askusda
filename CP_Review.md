# Cursor Application & LLM Integration Review

## 1. Executive Summary
- I used CoPilot to help review and port the CIC AskUSDA Chatbot.
- I had it summarize the code developer-provided documents.
- I had it create workflows to allow GitHub-to-AWS deployment of CloudFormation code.
- Struggles aside, there is a net benefit in using CP to aid in daily tasks (20%).

## 2. Application Architecture 
- Normal VS Code interface (thanks for the VIM plugin).
- VSC is one of the most common GUI IDEs/Coding applications.

## 3. LLM Integration
- CoPilot was used via the side-bar chat integration.
- This integration has access to the project files.
- Edits are totally in user control.

## 4. User Experience & Workflow
- The GUI is clunky for a CLI users but overall it works well.
- The tool integration is an add-on but blends in.
- The lack of a working ssh into the AWS posed considerable workflow slowdown by not having CP be able to quickly iterate through issues. This is a USDA Network issue.

## 5. Security & Compliance
- You can tailor the amount of autonomy CP uses.
- All commands are printed out before user approval.

## 6. Strengths & Opportunities
- Document summarization is a CP strength (as with most LLMs).
- Short task/code creation is proved successful.
- CP struggled with the more complex GH Workflow creation and other lengthy tasks.
- I reached 50% monthly usage in 1 week of this project.
- The lack of memory is a clear handicap when comparted to Claude.
- SSH/AWS Account integration would make debugging much easier and improve tool effectiveness.
